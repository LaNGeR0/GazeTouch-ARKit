# GazeTouch Windows — ARKit receiver

Это Windows-часть новой системы. Она принимает UDP-пакеты от iPhone-компаньона на порту 50555, калибрует взгляд по 16 точкам, управляет глобальным курсором Windows и выполняет левый клик по щипку.

## Запуск

1. Установи Python 3.13 x64.
2. Запусти `run_from_source.bat`.
3. Разреши GazeTouch входящее UDP-соединение в брандмауэре Windows.
4. На iPhone и ПК должна быть одна локальная Wi-Fi-сеть.
5. Запусти приложение iPhone и введи IPv4-адрес ПК, порт 50555.
6. Когда в Windows появится «Лицо: найдено», нажми «Калибровать · 16 точек».
7. Смотри на каждую точку только глазами; не нужно поворачивать голову намеренно.
8. После завершения калибровки нажми «Начать управление». F8 переключает управление, когда окно Windows активно.

## Порт

UDP 50555. Правило брандмауэра (PowerShell от администратора):

`New-NetFirewallRule -DisplayName "GazeTouch ARKit UDP" -Direction Inbound -Protocol UDP -LocalPort 50555 -Action Allow`

## Важно

Это тестовый релиз. В нём используются числовые gaze_features, полученные из ARKit `lookAtPoint` относительно середины глаз. Направление головы не является отдельной управляющей координатой. Точность зависит от качества ARKit и персональной калибровки. Камера телефона используется приложением iPhone для взгляда и руки; Iriun не нужен. Если фронтальная камера не видит руку из-под монитора, понадобится отдельная USB-камера для жестов.
