# GazeTouch — единый комплект iPhone + Windows

## Что это

Одна система из двух собственных приложений:
- **iPhone Air:** фронтальная TrueDepth-камера, ARKit для взгляда, Vision для щипка руки. Одно приложение использует камеру; Iriun и Beam не нужны.
- **Windows 10/11:** принимает координаты, проводит 16-точечную калибровку, сглаживает курсор и выполняет левый клик по жесту щипка. Курсор управляется глобально через Win32 и может работать поверх других приложений.

Данные передаются напрямую по локальной Wi-Fi-сети. Видеопоток не передаётся.

## Важно: статус этой версии

Это интегрированный **первый тестовый прототип**, а не проверенная финальная сборка. Windows-код проверен тестами математики калибровки, фильтра и защиты от повторных кликов. Однако iOS-проект требует облачной компиляции Xcode и проверки на реальном iPhone Air. ARKit `lookAtPoint` — оценка направления взгляда, а не точные экранные пиксели; поэтому обязательна калибровка и практическая проверка.

## Что нужно сделать — по порядку

### Шаг 1. Создать GitHub-репозиторий

1. Создай аккаунт или войди: https://github.com/
2. Создай репозиторий `GazeTouch-ARKit`.
3. Для самого простого бесплатного сценария выбери **Public**. Это означает, что исходный код будет публичным. В проекте нет паролей, токенов или личных данных. Если не хочешь публичный репозиторий, остановись и напиши — подберём другой вариант облачной сборки; условия бесплатных минут для private-репозиториев отличаются.

### Шаг 2. Загрузить комплект

Загрузи в корень репозитория всё содержимое этого архива, сохранив структуру:
- `.github/workflows/build-ios.yml`
- `iPhone/GazeTouchARKit/...`
- `Windows/...`

Можно через GitHub Desktop: https://desktop.github.com/

### Шаг 3. Собрать iPhone-приложение в облаке

1. Открой вкладку Actions в GitHub.
2. Выбери `Build GazeTouch iPhone app (unsigned IPA)`.
3. Нажми Run workflow.
4. Дождись результата.
5. Внизу завершённого запуска скачай Artifact `GazeTouchARKit-unsigned-IPA`.
6. Распакуй artifact — внутри будет `GazeTouchARKit-unsigned.ipa`.

GitHub Actions выполняет сборку на облачном macOS runner с Xcode. Вручную ставить Xcode на Windows не нужно.

### Шаг 4. Установить приложение на iPhone

1. Установи Sideloadly только с официального сайта: https://sideloadly.io/
2. Подключи iPhone к ПК по USB и подтверди доверие.
3. Открой Sideloadly, выбери iPhone, перетащи IPA.
4. Введи Apple Account для подписи и пройди проверку Apple.
5. Если iOS попросит Developer Mode, включи его в Settings → Privacy & Security → Developer Mode и перезагрузи телефон.

Бесплатная персональная подпись Apple обычно действует 7 дней. Это ограничение Apple, не GazeTouch. Для продолжения тестов потребуется периодически переподписывать приложение.

### Шаг 5. Запустить Windows-часть

1. На Windows установи Python 3.13 x64: https://www.python.org/downloads/
2. Открой папку `Windows`.
3. Запусти `run_from_source.bat`. При первом старте он создаст окружение и установит зависимости.
4. Если iPhone не подключается, запусти `allow_firewall.bat` от имени администратора.
5. На Windows открой PowerShell и выполни `ipconfig`; найди IPv4-адрес активного Wi-Fi адаптера.

### Шаг 6. Соединить iPhone и ПК

1. iPhone и ПК должны быть в одной Wi-Fi-сети.
2. Оставь телефон под монитором фронтальной камерой к себе.
3. Закрой Iriun на телефоне.
4. Запусти `GazeTouch Sensor` на iPhone.
5. Введи IPv4 компьютера и порт `50555`.
6. Нажми `Connect and start tracking`.
7. В Windows дождись статуса «Лицо: найдено» и пакетов.

### Шаг 7. Калибровка и управление

1. Нажми «Калибровать · 16 точек».
2. На каждой точке перемещай только глаза; не старайся поворачивать голову вслед за точкой.
3. Если калибровка завершилась, нажми «Начать управление».
4. F8 — включить/приостановить управление, когда окно GazeTouch активно.
5. Для клика сомкни большой и указательный пальцы, затем разомкни их. Одно смыкание даёт один клик, повторное возможно только после отпускания и cooldown.

## Если не получается

Не пытайся самостоятельно менять исходный код. Пришли:
- скриншот ошибки GitHub Actions, если упала сборка;
- скриншот GazeTouch Windows и экрана iPhone, если приложение установилось, но связи нет;
- текст ошибки Sideloadly, если не удаётся установить IPA.

## Технические замечания

- iPhone камера используется только одним приложением.
- Vision hand pose выполняется на каждом третьем ARKit кадре; это компромисс производительности, который можно будет подстроить.
- На iPhone рассчитывается `gaze_features` из `ARFaceAnchor.lookAtPoint` и центра глаз. Windows подгоняет полиномиальную модель по 16 точкам.
- Для текущей версии рука должна попадать в поле зрения фронтальной камеры. Если телефон под монитором не видит руку, потребуется отдельная USB-камера для руки — тогда её обработка останется на Windows.
- Полноэкранная область Windows — весь виртуальный рабочий стол. Точность зависит от фактической геометрии экранов и качества сигнала.
